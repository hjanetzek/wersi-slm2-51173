# Wersi SLM-2 Z8611 Firmware Workspace

## Quick Reference

### Build & Install
```bash
./build_firmware.sh              # patch + assemble + verify (most common)
./build_firmware.sh install      # also install to MAME ROM dirs
./build_firmware.sh asm          # just regenerate firmware.asm + firmware.lst
```

### Navigate Firmware Listing
```bash
python3 lst_nav.py 0x0E62             # show code at address
python3 lst_nav.py synthesis_output   # search by label name
python3 lst_nav.py --list norm        # list labels matching 'norm'
python3 lst_nav.py 0x0E62 --full      # show until next section boundary
python3 lst_nav.py 0x0E62 -n 50       # show 50 lines
python3 lst_nav.py --refs synthesis_loop_reentry -n 3  # show all call sites with context
```

### Apply Patches
Patches are in `patched_roms/apply_patches.py`. Each patch is a tuple:
```python
(offset, original_byte, patched_byte, "description")
```
Comment/uncomment patches to test. Build applies them from `sr0106_original.bin`.

### Run Tests

**Synthetic tests (slm2test single-voice harness):**
```bash
./run_test.sh --list                    # list available synthetic tests
./run_test.sh c4_dds                    # run one test
./run_test.sh lfsr_ocean -g             # run + open GTKWave
./run_test.sh all                       # run all tests
```

**EX-20 capture replay (slm2test):**
```bash
./run_test.sh --capture path/to/capture.bin
./run_test.sh --capture capture_ocean.bin --slot 4   # filter to slot 4
```

**Full EX-20 driver with tracing:**
```bash
# Trace voice 4 only (tag filter):
WERSI_DAC_TRACE=voice4.bin WERSI_TRACE_TAG=voice4 \
  WERSI_AUTOPLAY=1 WERSI_NOTE=65 WERSI_CAPTURE=capture.bin \
  ./mamemuse ex20 -seconds_to_run 10 -wavwrite out.wav -oslog

# Convert trace to VCD:
python3 dac_trace_to_vcd.py voice4.bin -o voice4.vcd
gtkwave voice4.vcd
```

**CSV instruction trace (detailed per-instruction):**
```bash
WERSI_Z8_TRACE=trace.csv WERSI_DAC_TRACE=dac.bin \
  ./run_test.sh --capture capture.bin
```

### Parse EX-20 Captures
```python
import struct
with open('capture.bin', 'rb') as f:
    while True:
        buf = f.read(272)  # 16-byte header + 256 slave RAM
        if len(buf) < 272 or buf[0:2] != b'RA': break
        slot, bank = buf[2], buf[3]
        cmd = buf[6]  # bit 0=SETUP, bit 1=STOP, bit 2=PARAM_UPDATE
        cycles = struct.unpack_from('<Q', buf, 8)[0]
        data = buf[16:]  # 256 bytes of slave RAM
        # Key slave RAM addresses:
        #   $D4-$F3: micro-program bytecodes (FREQ block)
        #   $F4: LDEI byte count
        #   $F5: micro-program source offset
        #   $F6: waveform source offset
        #   $F7: R14 init / freq step
        #   $F8: command byte
        #   $F9: TMR/routing
        #   $FA: MODE register (bits 5:4=mode, 3:0=sub, 7=no pitch mod, 6=coeff)
        #   $FB: reg[$11] init (LFSR seed / ACC3_HI)
        #   $FC: PITCH_HI (bits 3:0=coeff high, 7:6=EXSLA set by bus handshake)
        #   $FD: PITCH_LO (coeff low)
        #   $FE: reg[$14] init
        #   $FF: reg[$15] init
```

### Parse DAC Trace Binary
```python
import struct
with open('dac.bin', 'rb') as f:
    hdr = f.read(8)  # 'WDAC' + version
    while True:
        rec = f.read(16)
        if len(rec) < 16: break
        cycles = struct.unpack_from('<Q', rec, 0)[0]
        pc = struct.unpack_from('<H', rec, 8)[0]
        event = chr(rec[10])
        # Event types:
        #   'D' = DAC write (16 bytes)
        #   'L' = DAC latch / T_OUT edge (16 bytes)
        #   'R' = RAUD pulse (16 bytes)
        #   'S' = Synthesis state (28 bytes: 16 + 12 ext)
        #   'U' = Unmapped register read (16 bytes)
        #   'E' = reg[$1E] change (24 bytes: 16 + 8 ext)
        if event == 'S':
            ext = f.read(12)  # R5,R7,MODE,R15, SPH,PRE0,R6,pad
        elif event == 'E':
            ext = f.read(8)   # prev_pc × 4 (ring buffer)
```

## Synthesis Modes

| MODE bits 5:4 | Mode | Micro-ops | Description |
|---------------|------|-----------|-------------|
| $20 | Mode A | $20/$82/$AC/$C4 | Oversampled wavetable + direct DDS |
| $00 | Mode B | $CF/$DA/$E9 | Variable-duty DDS |
| $10 | Mode C | $F2 | Programmable-wrap DDS |

## Mode A Oversampling Ladder

| Sub | Micro-op | Chain | Timer | R14 role |
|-----|----------|-------|-------|----------|
| 0-5 | $20 | 8× oversample | T=$80 | working sample |
| 6 | $82 | 4× oversample | T=$80 | working sample |
| 7 | $AC | 2× oversample | T=$80 | working sample |
| 8-13 | $C4 | 1× direct DDS | T=R14 | freq step const |
| 14-15 | $19 | silence | T=$00 | N/A |

**WARNING**: Sub 7→8 boundary changes R14 meaning. Crossing it mid-note corrupts output.

## Micro-program Opcodes (FREQ block)

| Bits 1:0 | Type | Dispatch |
|----------|------|----------|
| 00 | Type D | ROM[$01B2 + (opcode>>1 & $7E)] |
| 01,10,11 | Type B | ROM[$0192 + (opcode<<1 & $1E)] |

Common opcodes:
- `$00` = NOP / REPEAT
- `$01` = LOAD R8:R9 (3 bytes: opcode, high, low)
- `$10` = LFSR noise (4 bytes: opcode, state, coefficient, counter)
- `$A0` = wavetable_acc (2 bytes)

## Active Investigation

See `WIP_ocean_crash.md` for the LFSR mode-bouncing investigation.
Key finding: the 12×16 multiply's carry at $0D60 acts as a sign test on ACC,
routing positive/negative ACC through different paths. For LFSR noise (signed
signal crossing zero), this causes mode bouncing and pitch distortion.
